# Contributing Guidelines / Hướng Dẫn Đóng Góp

## 🇬🇧 English
Contributions to the public client SDKs (`sdk/js`, `sdk/php`, `sdk/python`, `sdk/go`), web server routing configurations (`configs/`), and bilingual documentation (`docs/en`, `docs/vi`) are welcome via Pull Requests.

## 🇻🇳 Tiếng Việt
Mọi đóng góp nâng cấp bộ thư viện SDK (`sdk/js`, `sdk/php`, `sdk/python`, `sdk/go`), cấu hình mẫu Web Server (`configs/`) và tài liệu song ngữ (`docs/en`, `docs/vi`) đều được hoan nghênh qua Pull Request.
